# What I hope to learn

1. How to make good charts, which are not only appealing but also make the audience grab information quickly.
2. How to use data to tell stories, which would be more attractive to audience, rather than just reporting the research.
3. Useful tools that would help make charts quickly, or make appealing data story presentations.

# Portfolio 

## Assignment: [Visualizing Government Debt](visualizing-government-debt)
A hands-on Tableau exercise. I built visualizations of government debt data, then set up a new GitHub page to present them, including embedding chart images and organizing the write-up.

## Assignment: [Critique by Design](critique-by-design)
An exercise in thinking critically about other people's visualizations. I picked an existing chart of the deadliest animals in the world, analyzed what worked and what didn't, and redesigned it. Then I shared the redesign with my classmates, recorded their feedback, and revised the chart based on what I heard.
